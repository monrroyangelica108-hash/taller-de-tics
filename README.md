# Portal de Servicios Estudiantiles

## Propósito
Este proyecto académico presenta un sitio web informativo de ejemplo para estudiantes. Incluye información general sobre biblioteca, orientación académica y eventos, además de un formulario de contacto de demostración.

## Archivos
- `index.html`: página de inicio.
- `servicios.html`: descripción de los servicios, lista y tabla.
- `contacto.html`: formulario con campos obligatorios y validación del navegador.
- `css/estilos.css`: colores, tipografía, tarjetas, navegación y diseño adaptable a móviles.
- `img/`: carpeta reservada para imágenes locales si el equipo decide agregarlas.

## Cómo abrir el proyecto
1. Descarguen y descompriman la carpeta.
2. Abran `index.html` con un navegador como Chrome o Edge.
3. Utilicen el menú superior para visitar Inicio, Servicios y Contacto.
4. Para probar el formulario, entren en Contacto, completen los campos y pulsen “Validar formulario”.

## Importante
Las imágenes de ejemplo se cargan desde internet, por lo que necesitan conexión. El formulario es una demostración: valida los campos en el navegador, pero no envía datos a un servidor ni a un correo real. La información de servicios es ilustrativa y debe verificarse por canales oficiales antes de publicarse como información institucional.

## Reparto de tareas sugerido
- Integrante 1 – Estructura: coordina `index.html`, la navegación y la revisión semántica.
- Integrante 2 – Contenido: coordina `servicios.html`, las imágenes, listas y tabla.
- Integrante 3 – Interfaz: coordina `contacto.html`, el formulario y `css/estilos.css`.

Todos los integrantes deben aportar a otra sección, participar en las pruebas y poder explicar las decisiones técnicas.

## Registro de tres pruebas
| Acción | Resultado esperado | Resultado obtenido | Corrección aplicada |
|---|---|---|---|
| Abrir Inicio y pulsar Servicios | Se abre `servicios.html` | Pendiente de ejecutar por el equipo | Anotar aquí si fue necesario corregir el enlace |
| Enviar el formulario vacío | El navegador marca campos obligatorios | Pendiente de ejecutar por el equipo | Anotar aquí si fue necesario corregir la validación |
| Abrir las páginas desde un celular o vista móvil | El contenido se adapta al ancho de pantalla | Pendiente de ejecutar por el equipo | Anotar aquí si fue necesario ajustar CSS |

## Limitaciones
- El formulario no almacena ni envía información.
- Los datos y servicios descritos son ejemplos académicos.
- Las imágenes externas requieren internet.
